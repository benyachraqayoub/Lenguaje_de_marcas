# 📂 Control de versiones

Material de apoyo para configurar y utilizar el control de versiones.

El control de versiones permite registrar los cambios de un proyecto a lo largo del tiempo, consultar versiones anteriores y colaborar con otras personas. En esta sección encontrarás una guía para configurar las herramientas necesarias y empezar a gestionar tus proyectos con Git y GitHub.
