# Ejercicio 9 — Objeto anidado

## Solución

```json
{
  "nombre": "Elena",
  "edad": 25,
  "direccion": {
    "calle": "Calle Mayor, 12",
    "ciudad": "Valencia",
    "codigoPostal": "46001"
  }
}
```

## Tipos de Datos Utilizados
* **nombre:** String (Nombre de la persona)
* **edad:** Number (Edad de la persona)
* **direccion:** Object (Objeto con los datos de la dirección)
* **calle**, **ciudad** y **codigoPostal:** String. El código postal se guarda como texto para conservar ceros iniciales si los hubiera.

**Objetivo:** Practicar cómo incluir un objeto dentro de otro objeto JSON.
