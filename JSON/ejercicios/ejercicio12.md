# Ejercicio 12 — Lista de alumnos

## Solución

```json
{
  "alumnos": [
    {
      "nombre": "Lucía",
      "edad": 18,
      "aprobado": true
    },
    {
      "nombre": "Mateo",
      "edad": 20,
      "aprobado": true
    },
    {
      "nombre": "Sofía",
      "edad": 19,
      "aprobado": false
    },
    {
      "nombre": "Daniel",
      "edad": 21,
      "aprobado": true
    }
  ]
}
```

## Tipos de Datos Utilizados
* **alumnos:** Array del objeto **clase** con cuatro objetos, uno por alumno.
* **nombre:** String.
* **edad:** Number.
* **aprobado:** Boolean.

**Objetivo:** Practicar arrays de objetos con diferentes tipos de datos.
