# Ejercicio 7 — Arrays con diferentes tipos

## Solución

```json
{
  "datos": [
    "Auriculares",
    29.99,
    true,
    null
  ]
}
```

## Tipos de Datos Utilizados
* **"Auriculares":** String (Nombre del producto)
* **29.99:** Number (Precio del producto)
* **true:** Boolean (Indica que está disponible)
* **null:** Null (Valor vacío o no especificado)

**Objetivo:** Recordar que un array JSON puede contener valores de diferentes tipos.
