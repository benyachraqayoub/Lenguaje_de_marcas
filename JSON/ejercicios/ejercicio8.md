# Ejercicio 8 — Array de objetos

## Solución

```json
{
  "alumnos": [
    {
      "nombre": "Lucía",
      "edad": 18
    },
    {
      "nombre": "Mateo",
      "edad": 20
    },
    {
      "nombre": "Sofía",
      "edad": 19
    }
  ]
}
```

## Tipos de Datos Utilizados
* **alumnos:** Array (Lista de alumnos)
* Cada alumno es un objeto con **nombre** de tipo String y **edad** de tipo Number.

**Objetivo:** Practicar un array que contiene objetos JSON.
