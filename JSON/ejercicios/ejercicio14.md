# Ejercicio 14 — Lista de videojuegos

## Solución

```json
{
  "videojuegos": [
    {
      "titulo": "Celeste",
      "genero": "Plataformas",
      "precio": 19.99,
      "multijugador": false
    },
    {
      "titulo": "Stardew Valley",
      "genero": "Simulación",
      "precio": 0,
      "multijugador": true
    },
    {
      "titulo": "Overcooked! 2",
      "genero": "Cocina",
      "precio": 24.99,
      "multijugador": true
    }
  ]
}
```

## Tipos de Datos Utilizados
* **videojuegos:** Array con tres objetos, uno por videojuego.
* **titulo** y **genero:** String.
* **precio:** Number. El segundo videojuego tiene un precio de **0**.
* **multijugador:** Boolean. El primer videojuego tiene el valor **false**.

**Objetivo:** Practicar diferentes tipos de datos en objetos con una estructura uniforme.
