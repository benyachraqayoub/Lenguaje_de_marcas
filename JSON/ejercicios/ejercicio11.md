# Ejercicio 11 — Lista de películas

## Solución

```json
{
  "peliculas": [
    {
      "titulo": "El viaje de Chihiro",
      "director": "Hayao Miyazaki",
      "año": 2001
    },
    {
      "titulo": "Parásitos",
      "director": "Bong Joon-ho",
      "año": 2019
    },
    {
      "titulo": "Interestelar",
      "director": "Christopher Nolan",
      "año": 2014
    }
  ]
}
```

## Tipos de Datos Utilizados
* **peliculas:** Array con tres objetos, uno por película.
* **titulo** y **director:** String.
* **año:** Number.

**Objetivo:** Practicar la estructura básica de un array de objetos.
