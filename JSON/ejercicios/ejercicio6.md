# Ejercicio 6 — Crear un array

## Solución

```json
{
  "nombre": "Ana",
  "aficiones": [
    "fútbol",
    "música",
    "videojuegos"
  ]
}
```

## Tipos de Datos Utilizados
* **nombre:** String (Nombre de la persona)
* **aficiones:** Array (Lista de aficiones)
* Cada afición es un String.

**Objetivo:** Practicar cómo incluir un array dentro de un objeto JSON.
