# Ejercicio 5 — Crear tu propio objeto

## JSON de Ejemplo
```json
{
  "titulo": "The Legend of Zelda: Breath of the Wild",
  "precio": 59.99,
  "disponible": true,
  "descripcion": "Un videojuego de acción y aventura de mundo abierto.",
  "descuento": null
}
```

## Tipos de Datos Utilizados
* **titulo:** String (Texto entre comillas)
* **precio:** Number (Número decimal sin comillas)
* **disponible:** Boolean (Valor lógico true)
* **descripcion:** String (Texto largo entre comillas)
* **descuento:** Null (Valor vacío o nulo)
