```json
{
  "productos": [
    {
      "nombre": "Auriculares",
      "precio": 39.99,
      "categoria": "Electrónica",
      "disponible": true
    },
    {
      "nombre": "Teclado",
      "precio": 54.5,
      "categoria": "Electrónica",
      "disponible": true
    },
    {
      "nombre": "Mochila",
      "precio": 32,
      "categoria": "Accesorios",
      "disponible": false
    },
    {
      "nombre": "Cuaderno",
      "precio": 4.25,
      "categoria": "Papelería",
      "disponible": true
    }
  ]
}
```

## Tipos de Datos Utilizados
* **productos:** Array del objeto **tienda** con cuatro objetos, uno por producto.
* **nombre** y **categoria:** String.
* **precio:** Number.
* **disponible:** Boolean.

**Objetivo:** Practicar objetos con varias propiedades dentro de un array.
