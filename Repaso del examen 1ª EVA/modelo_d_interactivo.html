Archivo 2: respuestas.txt (Tareas 1, 2 y 5 explicadas)
Texto explicativo 
=== TAREA 1: 6 ERRORES DETECTADOS ===
1. nombre: 'Clínica Médica Turia Salud' -> La clave "nombre" carece de comillas dobles y su valor está escrito con comillas simples en vez de comillas dobles.
2. "urgenciasActivas": True -> En JSON los booleanos se escriben en minúsculas (true).
3. "plantasEdificio": "4" -> Error de tipo de dato: el número de plantas del edificio es un entero (4) de tipo Number, no un texto ("4").
4. "horario": [ "apertura": "08:00", "cierre": "21:00" ] -> Error estructural: contiene pares "propiedad": valor pero usa corchetes de array [ ] en lugar de llaves de objeto { }.
5. "especialidades": ["Cardiología", "Traumatología", "Dermatología",] -> Error de sintaxis: sobra la coma final después del último elemento del array ("Dermatología").
6. "directorMedico": "null" -> Error de tipo: debe usarse el literal null sin comillas en vez de la cadena de texto "null".

=== TAREA 5: COMPROBACIÓN Y NAVEGACIÓN PROFUNDA ===
(a) Rutas de acceso profundas:
- Medicamento del segundo episodio del historial del segundo paciente (PAC02, índice 1 -> historial índice 1):
  clinica.pacientes[1].historial[1].tratamiento.medicamento
- Precio por unidad de la segunda prueba adicional de la primera cita (CIT01, índice 0 -> pruebasAdicionales índice 1):
  clinica.citas[0].pruebasAdicionales[1].precioUnidad

(b) Cómo averiguar qué citas corresponden a MED01 y están Confirmadas:
Recorriendo el array clinica.citas y filtrando aquellos objetos donde cita.medicoId === "MED01" && cita.estado === "Confirmada".

(c) Cómo averiguar qué pacientes no tienen seguro médico contratado:
Recorriendo el array clinica.pacientes y seleccionando aquellos objetos cuya propiedad seguro sea igual a null.
