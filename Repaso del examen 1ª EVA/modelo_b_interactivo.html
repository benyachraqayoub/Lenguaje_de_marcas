Archivo 2: respuestas.txt (Tareas 1, 2 y 5 explicadas)
Texto explicativo 
=== TAREA 1: 6 ERRORES DETECTADOS (BLOQUE 8 UD2) ===
1. nombre: 'Digitech Store Valencia' -> La propiedad "nombre" no lleva comillas dobles obligatorias y el valor usa comillas simples en lugar de comillas dobles.
2. "ivaGeneral": "21" -> Error de tipo de dato: el porcentaje de IVA (21) es un número entero (Number), pero está escrito entre comillas como texto (String).
3. "envioGratisDesde": 49,90 -> Error de sintaxis: los números decimales en JSON se escriben con punto (49.90), nunca con coma.
4. "ventaActiva": True -> Error de sintaxis: los booleanos en JSON se escriben en minúsculas (true / false).
5. "metodosPago": ["tarjeta", "bizum", "transferencia",] -> Error de sintaxis: sobra la coma final detrás del último elemento del array ("transferencia").
6. "telefonoSoporte": "null" -> Error de tipo de dato: "null" con comillas es un texto; para representar que aún no tiene teléfono de soporte debe usarse null sin comillas.

=== TAREA 2: JUSTIFICACIÓN DE TIPOS ===
- ivaGeneral (number -> 21): Es un valor numérico con el que se realizan cálculos matemáticos de impuestos.
- codigoPostal (string -> "46001"): Es un código identificador postal con el que no se opera aritméticamente y que en muchas provincias empieza por 0 (como "03001"), el cual se perdería si fuera number.
- telefonoSoporte (null -> null): Refleja la ausencia de dato mediante el tipo Null nativo de JSON.

=== TAREA 5: COMPROBACIÓN Y NAVEGACIÓN ===
(a) Rutas de acceso:
- Marca de la ficha técnica del segundo producto (P002):
  tienda.productos[1].fichaTecnica.marca
- Cantidad de la primera línea del primer pedido (PED01):
  tienda.pedidos[0].lineas[0].cantidad

(b) Cómo averiguar qué pedidos pertenecen al cliente C001:
Recorriendo el array tienda.pedidos y filtrando aquellos objetos cuya propiedad clienteId sea igual a "C001".

(c) Cómo averiguar qué clientes no tienen suscripción VIP activa:
Recorriendo el array tienda.clientes y comprobando qué objetos tienen la propiedad suscripcionVip con valor igual a null.
